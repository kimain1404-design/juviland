# 쥬비랜드 main-section03 – 농업 인재의 시작부터 미래까지

5가지 솔루션 카드가 스크롤에 맞춰 01 → 05 순서로 올라오고, 화면 위쪽에 멈춰 다음 카드가 앞 카드를 완전히 덮으며 쌓이는 섹션입니다.

- 피그마: main-section03(pc) `21:1459` · main-section03(mob) `38:1327`
- 배포 주소: https://kimain1404-design.github.io/juviland/main-section03/

## 파일 구성

```
main-section03/
├─ index.html                           (주소로 바로 열리도록 이름 유지)
├─ main-section03.css                   반응형 레이아웃 + 등장 모션 + 카드 쌓기
├─ main-section03.js                    순서대로 등장 + 카드 쌓기 (iframe 대응)
├─ main-section03-liveklass.html        라이브클래스에 붙여 넣을 iframe 코드
├─ README.md
└─ assets/
   ├─ main-section03(pc)-card1~5.webp   pc 일러스트 (카드 오른쪽, 2배 해상도)
   └─ main-section03(mob)-card1~5.webp  mob·태블릿 일러스트 (카드 위쪽)
```

## 배포

`juviland` 저장소 맨 위에 `main-section03` 폴더를 통째로 올립니다 (`.nojekyll`은 저장소 맨 위에 이미 있음).

## 반응형

| 구간 | 폭 | 동작 |
|---|---|---|
| main-section03(pc) | 1200px 이상 | 1600 시안 비율로 축소. 텍스트 왼쪽, 그림 오른쪽 (1600px 이상은 원본 크기) |
| 태블릿 | 768 ~ 1199px | (mob) 배치. 글자 크기는 648px 화면 기준에서 고정, 카드는 화면 폭을 채움 (좌우 여백 = 화면 폭의 5.6%). 그림은 3:2 비율 유지, 높이 460px까지 |
| main-section03(mob) | 767px 이하 | 1080 시안 비율 그대로. 그림 위, 텍스트 아래 |

## 모션

- 등장: 섹션 제목 → 카드 01~05가 화면에 들어올 때 아래에서 올라옴. 카드가 올라온 뒤 그림이 한 박자 늦게 떠오름. 여러 장이 한꺼번에 보여도 0.14초 간격으로 01부터 순서대로.
- 카드 쌓기: 카드가 화면 위쪽(PC 80px, 태블릿·모바일 56px)에 멈추고, 다음 카드가 같은 위치로 올라와 앞 카드를 완전히 덮음. 덮이는 카드는 살짝 작아지고 어두워짐. 멈추는 위치는 `main-section03.css`의 `--stack-top`으로 조절 (라이브클래스 상단 메뉴바에 가려지면 값을 키우세요).
- 카드가 화면보다 크면 아랫부분이 보이도록 더 위에서 멈춤.
- 깃허브 페이지에서 직접 열면 CSS `position: sticky`로, 라이브클래스 iframe 안에서는 부모 화면 스크롤을 감지해 `main-section03.js`가 같은 움직임을 재현합니다 (오차 몇 px 이내).
- "동작 줄이기" 설정 사용자는 모션 없이 바로 보입니다.

## 라이브클래스에 넣기

에디터 HTML(`<>`) 모드에 `main-section03-liveklass.html` 코드를 붙여 넣습니다. 높이 식이 계산하는 값:

- PC(1200px 이상): `157.075vw`, 1600px 이상은 `2513.2px`
- 1199px 이하: `703.02vw`, `296.3vw + 2635.5px`, `4935.5px` 중 가장 작은 값 (모바일 → 태블릿 그림 커짐 → 그림 상한)
- 끝의 `+ 1px`은 바닥이 잘리지 않게 하는 여유분입니다.

320~2560px 18가지 폭에서 iframe 높이와 실제 섹션 높이 차이 0.2px 이내로 검증했습니다. 글자 크기, 카드 높이, 그림 상한을 바꾸면 이 식도 수정해야 합니다.
