## 이름 규칙

| 대상 | 규칙 | 예시 |
|---|---|---|
| 폴더 | `main-sectionNN` | `main-section02/` |
| 페이지 | `index.html` (폴더 주소로 바로 열리도록 고정) | `main-section02/index.html` |
| 스타일·스크립트 | `main-sectionNN.css`, `main-sectionNN.js` | `main-section02.css` |
| 이미지 (pc·mob 공통) | `main-sectionNN-이름` | `main-section02-bg.jpg` |
| 이미지 (pc 전용) | `main-sectionNN(pc)-이름` | `main-section02(pc)-scene.webp` |
| 이미지 (mob 전용) | `main-sectionNN(mob)-이름` | `main-section02(mob)-scene.webp` |
| 라이브클래스 코드 | `main-sectionNN-liveklass.html` | `main-section02-liveklass.html` |
| 인수인계 문서 | `main-sectionNN-HANDOFF.md` | `main-section02-HANDOFF.md` |

- `(pc)`, `(mob)`는 피그마 프레임 이름 `main-sectionNN(pc)`, `main-sectionNN(mob)`과 맞춘 것입니다.
- 저장소 맨 위의 `.nojekyll`은 GitHub Pages가 파일을 그대로 보여주도록 하는 빈 파일입니다. 지우지 마세요.
