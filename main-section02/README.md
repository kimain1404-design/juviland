# 쥬비랜드 main-section02 – WHY ZUVILAND?

"왜 농업 인재의 여정을 끝까지 연결해야 할까요?" 섹션. 지표 카드 3개와 마무리 문장이 스크롤에 맞춰 순서대로 나타납니다.

- 피그마: main-section02(pc) `21:1328` · main-section02(mob) `38:1284`
- 배포 주소: https://kimain1404-design.github.io/juviland/main-section02/

## 파일 구성

```
main-section02/
├─ index.html                        (주소로 바로 열리도록 이름 유지)
├─ main-section02.css                반응형 레이아웃 + 모션
├─ main-section02.js                 순서대로 등장 + 숫자 카운트
├─ main-section02-liveklass.html     라이브클래스에 붙여 넣을 iframe 코드
├─ README.md
└─ assets/
   └─ main-section02-leaf.png        마무리 박스 잎사귀 (pc·mob 공통)
```

## 배포

`juviland` 저장소 맨 위에 `main-section02` 폴더를 통째로 올립니다 (`.nojekyll`은 저장소 맨 위에 이미 있음).

## 반응형

| 구간 | 폭 | 동작 |
|---|---|---|
| main-section02(pc) | 1200px 이상 | 1600 시안 비율로 축소, 카드 3열 (1600px 이상은 원본 크기) |
| 태블릿 | 768 ~ 1199px | (mob) 배치. 글자 크기는 648px 화면 기준에서 고정, 콘텐츠는 화면 폭을 채움 (좌우 여백 = 화면 폭의 5.6%) |
| main-section02(mob) | 767px 이하 | 1080 시안 비율 그대로 |

글꼴이 바뀌어 글자가 넓어져도 박스 밖으로 넘치지 않고 박스 안에서 줄바꿈되며, 카드는 자기 영역 밖의 내용을 잘라냅니다.

## 모션

1. 머리말: 태그 → 제목(줄 단위) → 설명
2. 지표 카드: 0.16초 간격으로 올라옴 → 숫자 카운트(117,113 / 85) · "관리 공백"은 왼쪽→오른쪽으로 그려짐 → 출처 → 체크 아이콘 → "○○ 필요" 문구. 모바일은 바깥 카드가 먼저 나온 뒤 세 줄이 차례로.
3. 마무리: 연결선이 내려옴 → 점 → 남색 박스가 점에서 펼쳐짐 → 잎사귀 → 영어 → 한글 제목 → 마지막 문장 → 밑줄

라이브클래스 iframe 안에서도 부모 페이지 스크롤에 맞춰 동작합니다. "동작 줄이기" 설정 사용자는 모션 없이 완성 화면이 보입니다.

## 라이브클래스에 넣기

에디터 HTML(`<>`) 모드에 `main-section02-liveklass.html` 코드를 붙여 넣습니다. 높이 식이 계산하는 값:

- PC(1200px 이상): `55.62vw + 2.95px`, 1600px 이상은 `892.83px`
- 1199px 이하: `270.42vw + 5.62px`, 648px 이상은 `1758.3px`
- 끝의 `+ 1px`은 바닥이 잘리지 않게 하는 여유분입니다.

320~2560px 24가지 폭에서 iframe 높이와 실제 섹션 높이 차이 0.4px 이내로 검증했습니다. 글자 크기나 여백을 바꾸면 이 식도 수정해야 합니다.
